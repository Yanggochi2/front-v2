## 배치 규칙 (캔버스)
한 줄 5개, 간격 160 이상. 라이트 블록 위, 다크 블록은 같은 모양으로 +7600 아래. 겹치면 재배치한다.

## 프로토타입
사이드바 메뉴 → 각 화면. 버튼 흐름은 [간호사 등록 → 안내 창(한 명 더 등록 / 간호사 명단)], [간호사 정보 수정 → 간호사 명단], [병동 만들기 → 관리 링크 → 근무표 빈 상태].
시작 지점: 근무표, 병동 만들기 — 각각 라이트·다크.
